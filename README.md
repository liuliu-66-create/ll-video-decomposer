# ll-video-decomposer

一个专业的五层视频拆解 Skill。输入逐字稿、本地视频或音频、视频链接，系统分析视频的选题、开头、结构、表达和成功边界。

它不仅复述内容，还会解释视频为什么有效，提炼可以复用的开头方法、内容结构和表达技巧，并识别不能直接复制的成功因素。

每次完成拆解后，默认会在视频所在目录保存一份 Markdown 报告，同时在对话中展示主要结论。只有用户明确要求不保存时，才只在对话中输出。

## 支持的输入

- 直接粘贴逐字稿，或提供逐字稿文件
- 提供 `.mp4`、`.mov`、`.mkv`、`.webm` 等本地视频
- 提供 `.wav`、`.mp3`、`.m4a` 等本地音频
- 提供视频链接

## 视频链接的稳定顺序

1. 先尝试直接下载。
2. 失败后，在 Chrome 登录并播放视频，再尝试已加载资源或缓存。
3. 需要读取 Chrome 登录状态时，完全退出 Chrome 后再试。
4. 仍然失败时，提供下载好的本地 MP4；这是最稳定的方式。

小红书可以先直接给链接。抖音建议先登录 Chrome 并播放一段。

## 输出内容

1. 基本信息和是否值得分析
2. 选题层
3. 开头层
4. 结构层
5. 表达层
6. 边界层
7. 最值得带走的三个方法

## 安装

将 `skills/ll-video-decomposer` 复制到 Codex skills 目录。媒体处理按需使用 `yt-dlp`、`ffmpeg` 和 Whisper；Skill 不会静默安装依赖。

使用示例：

```text
Use $ll-video-decomposer to analyze this video link: https://example.com/video
```
