# 输入证据与置信度规则

## 能力矩阵

| 输入 | 可以分析 | 不得猜测 |
|---|---|---|
| 完整视频 | 内容、画面、镜头、字幕、人声和 BGM | 无法确认的歌名、数据和幕后信息 |
| 只有音频 | 内容、人声、节奏和 BGM | 画面、镜头、字幕和视觉包装 |
| 只有逐字稿 | 选题、结构、表达、金句和内容价值 | 画面、人声听感、BGM和精确剪辑节奏 |
| 视频链接 | 下载成功后按完整视频处理 | 下载失败且没有媒体时的视听结论 |

把完整视频整理为“视频证据包”，至少包含：

- 原始视频和媒体基本信息
- 逐字稿
- 开头、正文、结尾和明显转场处的关键帧
- 关键帧时间点与来源类型
- 可获得的音轨信息
- 用户提供的平台、作者和表现数据

## 结论等级

- **已确认**：画面、逐字稿、音轨、平台元数据或用户材料直接支持。
- **合理推断**：多个证据共同支持，但原视频没有直接说明；使用“可能”“更像”等表达。
- **无法判断**：当前输入不覆盖该信息，明确缺少什么，不用相邻字段补写。

不必给每句话机械加标签；只在歌曲、身份、效果原因、数据和幕后信息等容易误判的位置标明置信度。

## BGM 规则

1. 只有平台元数据、可靠识曲结果或其他直接证据支持时，才能写歌曲名和艺术家。
2. 无法确认曲名但能读取音轨时，描述风格、情绪、节奏、主要声音、进入位置和承担的作用，并给出 3–5 个素材库搜索词。
3. 无法真实读取音轨时，写“当前输入无法判断 BGM”，不得根据视频主题猜测“科技感”“治愈感”等音乐风格。
4. 人声和音乐无法分离时，说明限制，不把混合音轨的声学特征冒充为具体乐器。

## 其他纪律

- 数据缺失时，不猜测播放量、互动率和爆款概率。
- 视听结论尽量带时间点或对应画面，确保可以回看验证。
- 不因为“不建议模仿”而停止报告；除非媒体无法读取，否则完成全部可分析维度。
- 延伸选题从受众问题和选题公式推导，不作未经验证的效果承诺。
